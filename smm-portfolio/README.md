# 🌟 Сайт-визитка SMM-маркетолога

Современный сайт-портфолио для SMM-маркетолога с встроенной админ-панелью и Telegram-уведомлениями.

## ✨ Возможности

### 🎨 Фронтенд
- ✅ Современный дизайн с градиентами и анимациями
- ✅ Адаптивная верстка для всех устройств
- ✅ Секция "О себе" с анимированным аватаром
- ✅ Портфолио с масонри-раскладкой (хаотично но органично)
- ✅ Форма обратной связи
- ✅ Интеграция с социальными сетями (Telegram, Instagram, Threads)
- ✅ Плавные анимации на Framer Motion
- ✅ Glassmorphism эффекты

### 🔐 Админ-панель
- ✅ Защищенная аутентификация (NextAuth.js)
- ✅ Редактирование профиля (фото, имя, описание, контакты)
- ✅ Управление портфолио (добавление/редактирование/удаление)
- ✅ Просмотр обращений с формы обратной связи
- ✅ Удобный интерфейс с вкладками

### 🤖 Telegram-бот
- ✅ Автоматические уведомления о новых обращениях
- ✅ Отправка информации о клиенте в Telegram

## 🚀 Технологии

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **Framer Motion** - анимации
- **Prisma** - ORM для работы с БД
- **SQLite** - база данных
- **NextAuth.js** - аутентификация
- **Lucide React** - иконки

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd smm-portfolio
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите свои значения:

```env
# Database
DATABASE_URL="file:./dev.db"

# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="ваш-секретный-ключ"  # Сгенерируйте с помощью: openssl rand -base64 32

# Admin credentials
ADMIN_EMAIL="admin@example.com"
ADMIN_PASSWORD="ваш-пароль"

# Telegram Bot (необязательно)
TELEGRAM_BOT_TOKEN="токен-вашего-бота"  # Получите у @BotFather
TELEGRAM_CHAT_ID="ваш-chat-id"          # Получите у @userinfobot
```

### 4. Инициализация базы данных

```bash
# Создание БД и таблиц
npm run db:push

# Заполнение начальными данными
npm run db:seed
```

### 5. Запуск проекта

```bash
# Режим разработки
npm run dev

# Продакшн сборка
npm run build
npm start
```

Сайт будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

## 🔑 Вход в админ-панель

1. Перейдите на [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
2. Введите email и пароль из `.env` файла
3. После входа вы попадете в админ-панель

По умолчанию:
- Email: `admin@example.com`
- Пароль: `admin123`

**⚠️ Обязательно измените пароль в продакшене!**

## 📱 Настройка Telegram-бота

### 1. Создание бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен бота

### 2. Получение Chat ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Нажмите "Start"
3. Скопируйте ваш Chat ID

### 3. Добавление в .env

```env
TELEGRAM_BOT_TOKEN="ваш-токен-бота"
TELEGRAM_CHAT_ID="ваш-chat-id"
```

После настройки вы будете получать уведомления о новых обращениях с сайта!

## 🎯 Использование админ-панели

### Редактирование профиля
1. Войдите в админ-панель
2. Вкладка "Профиль"
3. Измените нужные поля
4. Нажмите "Сохранить изменения"

### Управление портфолио
1. Вкладка "Портфолио"
2. Нажмите "Добавить проект"
3. Заполните форму (название, описание, изображение, категория)
4. Нажмите "Сохранить"

Для редактирования или удаления используйте кнопки на карточках проектов.

### Просмотр обращений
1. Вкладка "Обращения"
2. Просматривайте список обращений
3. Фильтруйте по статусу (все / непрочитанные)

## 🖼️ Добавление изображений

### Аватар
Поместите фото в `public/` и укажите путь в админ-панели, например: `/avatar.jpg`

### Портфолио
1. Поместите изображения в `public/portfolio/`
2. При создании проекта укажите путь, например: `/portfolio/project1.jpg`

## 🐛 Решение проблем

### База данных не создается
```bash
npx prisma generate
npx prisma db push
```

### Ошибка аутентификации
Проверьте `NEXTAUTH_SECRET` в `.env` - он должен быть уникальным.

### Telegram не отправляет уведомления
1. Проверьте токен бота и Chat ID
2. Убедитесь, что начали диалог с ботом (отправили `/start`)
